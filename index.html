01Introduction

CineMatch AI is a movie recommendation app. It uses two data mining techniques, K-Means clustering and Apriori association rules, to suggest movies from real user ratings.

I built it for my BCA Data Mining project in Python. A Streamlit web interface lets anyone search movies, explore the analysis and get recommendations without logging in.

02Problem statement

There are thousands of movies to choose from, and picking one takes time. People usually rely on a friend's advice or on one overall rating, and neither says much about their own taste.

This project asks two questions. Which movies are similar to each other? Which movies do the same people tend to like together? Both can be answered from rating data.

03Objectives

  • Clean and prepare real movie-rating data with Pandas.
  • Group similar movies with K-Means, and choose the number of groups with the Elbow Method and silhouette score.
  • Find movies liked together with Apriori, measured by support, confidence and lift.
  • Turn both results into working recommendations in an interactive web app.

04Dataset

I used the MovieLens latest-small dataset from GroupLens Research. It contains 9,742 movies, 100,836 ratings from 610 users, 19 genres, and ratings from 1996 to 2018. The files used are movies.csv, ratings.csv and tags.csv.

Preparation steps: removing duplicate and missing records, keeping a user's latest rating when a movie was rated twice, reading the release year from each title, splitting genres into a list, and calculating each movie's average rating and number of ratings.

DATASET NOTEAll results in this article come from real MovieLens ratings. No data was simulated. The dataset ends in 2018, so recent movies are not included.

05Methods

K-Means clustering

  • Each movie with at least 10 ratings (2,269 movies) is described by 22 numbers: average rating, number of ratings, release year and one 0/1 column per genre.
  • StandardScaler puts all features on the same scale, so the year does not outweigh the genres.
  • K-Means was run for k = 2 to 10. The Elbow Method (inertia) and the silhouette score guided the choice of k = 6.
  • To recommend, the app finds the chosen movie's cluster and ranks the movies in it by distance.

Apriori association rules

  • Each user is one basket. A movie goes into the basket only if the user rated it 4.0 or higher.
  • Only movies with at least 50 ratings are used, which gives 598 users and 450 movies.
  • Support is the share of users who liked every movie in the rule. Confidence is how often the "then" movie is liked by users who liked the "if" movies. Lift compares that with chance, and above 1 means the movies go together.

09Limitations

  • Small, older data: 610 users, ratings only until 2018.
  • Overlapping clusters: a silhouette score of 0.17 is low, because many movies share genres. The clusters are approximate.
  • Popular movies only: Apriori uses movies with at least 50 ratings, so rare movies get no rules. Toy Story, for example, has none with the default settings.
  • Association is not cause: a rule shows movies are liked together, not why.
  • No personal accounts: recommendations are not tailored to one user, and their accuracy was not measured.

10Conclusion

CineMatch AI shows that two basic data mining methods can turn rating data into useful movie suggestions. K-Means finds movies that are alike, and Apriori finds movies that people enjoy together.

The main lessons were that careful data preparation matters as much as the algorithms, and that weak results, such as a low silhouette score, should be reported honestly. Next steps are collaborative filtering, using the tags as extra information, trying the larger MovieLens datasets and measuring recommendation quality.
